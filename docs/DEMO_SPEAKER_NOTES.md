# NDC Data Explorer — 5-Minute Speaker Notes

**Live site:** https://ndc-data-explorer-e051f914.vercel.app  
**Bookmark:** `/dashboard?demo=1&sector=transport`

Print this page and keep it beside your laptop during the demo.

---

## Pre-flight (30 seconds)

1. Open production URL → select **Uganda**
2. Bookmark: `/dashboard?demo=1&sector=transport`
3. Press **F11** (fullscreen) or use the presenter toolbar
4. Pre-warm `/map` in a background tab (closes cold-start delay)
5. Close extra browser tabs

**Fastest start:** Home → **Start 5-minute demo** (enables presenter mode + Senior Decision-Maker role)

**Presenter toolbar (bottom-left):** Demo script · Fullscreen · Nav · Exit demo

## Timed script

| Time | Screen | Click / action | Say this |
|------|--------|----------------|----------|
| **0:00** | `/dashboard?demo=1&sector=transport` | Pause on Transport | *"Governments don't lack climate ambition — they lack a live picture of delivery. This cockpit answers that in one workspace."* |
| **0:25** | Same | Point at Climate TRACE banner | *"Not a static PDF — observed emissions, updated from satellite and facility data."* |
| **0:40** | Same | Five-questions overlay or Demo script panel | *"Ministries ask five operational questions: where we are, what moves the needle, policy impact, gaps, and what to prioritise next."* |
| **1:00** | Dashboard | Scroll progress / timeseries | *"Here: Uganda's transport target, pledges, and progress in one view — targets linked to evidence."* |
| **1:25** | `/map?demo=1` | Zoom Uganda; point at hotspots | *"Spatial layer — see where emissions actually come from, down to assets and districts."* |
| **2:00** | `/documents?tab=pathway&demo=1` | Show intervention pathway | *"Policies aren't separate from data — documents and measures trace back to NDC outcomes."* |
| **2:25** | `/climate-finance?demo=1` | Move carbon price slider once | *"Decision support: compare options by cost, abatement, and trade-offs — not abstract targets."* |
| **2:55** | `/dashboard?demo=1` | Open NDC AI; Tab → example → send | *"Ask in plain language — 'Are we on track for transport?' — grounded in this country's data."* |
| **3:35** | Dashboard | Stop clicking; look at audience | *"The shift: from reporting to decision support. From fragmented files to one operational system."* |
| **4:00** | Verbal or slide 8 | — | *"Honest challenges: mixed data sources, API warm-up, and adoption across ministries — not a UNFCCC submission tool."* |
| **4:25** | Verbal or slide 9 | — | *"Next: a searchable policy corpus per country, and a mobile app for field MRV and district briefings."* |
| **4:45** | Slide 10 | Verbal close | *"Uganda NDC Data Explorer — live Climate TRACE data. Happy to take questions."* |

**Target duration:** 4:45–5:15 with natural pauses.

## If running long — skip one

- **Skip map** (saves ~35s) — stay on dashboard through 2:00
- **Skip NDC AI** (saves ~40s) — go straight to punchline at 3:35

## If running short — dwell on

- Dashboard progress column and timeseries (1:00)
- Climate finance slider + MAC chart (2:25)

## Emergency one-liners

| Situation | Say |
|-----------|-----|
| Map slow to load | *"Satellite layer is loading — the architecture is live; on a cold start it can take a moment."* |
| NDC AI error | *"AI assistant uses live API keys — I'll show the dashboard evidence instead."* |
| Risk question | *"Risk screening is an illustrative prototype — adaptation geography is on the roadmap."* |
| AI 2030 badge | *"Forecasts use a lightweight model on serverless — full Python model runs locally."* |

**Do not say:** "mock data," "bug," "we didn't finish," "this route is legacy."
