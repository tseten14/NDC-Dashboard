# NDC Data Explorer — 3-Minute Demo Script

**Pre-flight:** Open `https://ndc-data-explorer-e051f914.vercel.app/select-country` → Uganda → bookmark:

```
/dashboard?demo=1&sector=transport
```

Set role to **Senior Decision-Maker** (auto-set when `?demo=1` is active). Enable demo panel via the **Demo** button in the header or keep `?demo=1` in the URL.

**Fallback:** Set `USE_MOCK_DATA=true` on the API if Climate TRACE is slow.

---

## [0:00–0:20] Opening (Problem framing)

**ON SCREEN:** `/dashboard?demo=1&sector=transport` — national view, Transport sector

**SCRIPT:**

> Let me ground this discussion in a very practical question: What does it actually take to make an NDC usable for day-to-day decision-making inside a government?

*Pause. Click once to activate the interface.*

> Today, in most countries, this still requires weeks of manually assembling fragmented data across ministries, sectors, and reporting systems.

*Point at Live Climate TRACE banner: observed emissions updated monthly — not a static PDF.*

---

## [0:20–0:50] Origin + user need (Uganda)

**ON SCREEN:** Same dashboard — national cockpit

**SCRIPT:**

> At the request of the Government of Uganda, we started to unpack what policymakers actually need in order to implement their NDC.

> Across ministries, we consistently heard the same set of questions.

*Open demo panel (Demo button) — Five Policy Questions overlay appears.*

---

## [0:50–1:20] The 5 policy questions

**ON SCREEN:** Demo overlay — five questions listed

**SCRIPT:**

> These are not abstract questions — they are operational:

1. Where are we today — in terms of emissions, actions, and progress?
2. Which sectors and policies have the highest impact potential?
3. What is the expected impact of a specific policy or investment?
4. Are we on track — and where are the gaps?
5. What should we prioritise next?

*Pause briefly.*

> Today, most systems cannot answer these questions in real time.

*Click Progress toward target column for question 4.*

---

## [1:20–2:10] Live walkthrough (3 screens)

### Screen 1 — Emissions / baseline (1:20)

**ON SCREEN:** Dashboard — Transport sector, timeseries + progress status

**SCRIPT:**

> Here, we move from static reporting to a live, integrated view of emissions and sector performance.

### Screen 2 — Sector / policy insight (1:45)

**CLICK:** Demo panel step → `/documents?tab=pathway&demo=1`

**SCRIPT:**

> The system connects emissions data with policy and sector-level information, allowing decision-makers to identify where interventions can have the greatest impact.

### Screen 3 — Scenario / decision support (2:00)

**CLICK:** Demo panel step → `/climate-finance?demo=1`

**SCRIPT:**

> And critically, it allows policymakers to compare options — not in abstract terms, but in terms of expected outcomes and trade-offs.

*Drag carbon price slider; click a MAC bar.*

---

## [2:10–2:35] Key shift (punchline)

**ON SCREEN:** Return to `/dashboard?demo=1&sector=transport`

**SCRIPT:**

> So what this really represents is a shift:

*Pause.*

> From data — to insight.

> From reporting — to decision support.

> From static NDCs — to operational systems for implementation.
