PART A — NON-TECHNICAL OVERVIEW
--------------------------------

A1. WHAT THIS PROJECT IS
  A web-based decision-support cockpit for Uganda’s NDC and related national
  strategies. It links targets, activities, observed emissions-style signals,
  progress indicators, and climate risk in one workspace.

A2. DATA SOURCES
  • Observed emissions: Climate TRACE API v7 (live via Express)
  • NDC targets & strategies: bundled in the application
  • Climate risk (demo): illustrative district layers in the repo
  • Delivery activities: saved in the user’s browser (localStorage)

A3. USERS
  Ministry staff, MRV focal points, programme managers, and executive briefings
  (role switcher in the UI — demo mode, no remote sign-in).


PART B — TECHNICAL OVERVIEW
---------------------------

B1. ARCHITECTURE

  frontend/     React SPA (Vite)
  server.js     Express API on port 8787 (default)
  routes/       emissions, cockpit catalog, risk, mock
  services/     Climate TRACE client, emissions aggregation, catalog
  config/       NDC targets, Climate TRACE helpers, cockpit catalog
  data/         Illustrative risk seed data

B2. EXPRESS API

  GET  /api/v1/emissions/timeseries
  GET  /api/v1/emissions/progress
  GET  /api/v1/emissions/summary
  GET  /api/v1/provenance
  GET  /api/v1/health/climatetrace
  GET  /api/v1/indicators/panel
  GET  /api/v1/catalog/activities
  GET  /api/v1/catalog/mitigation-options
  GET  /api/v1/risk/*

  Climate TRACE v7: https://api.climatetrace.org/v7/
  National sector totals: GET /v7/sources/emissions?gadmId=UGA&sectors=...
  Live rank: GET /v7/rankings/countries

B3. ENVIRONMENT

  VITE_API_BASE_URL=http://localhost:8787
  API_PORT=8787
  USE_MOCK_DATA=false

B4. NPM SCRIPTS

  npm run dev:all       — frontend + API
  npm run start:api     — API only
  npm run build         — production frontend build
