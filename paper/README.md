# NDC Data Explorer paper draft

NeurIPS 2026-style draft describing the Uganda NDC Data Explorer.

## Compile

Place the official `neurips_2026.sty` (from [neurips.cc](https://neurips.cc) / the 2026 author kit) in this directory, then:

```sh
pdflatex ndc_data_explorer.tex
pdflatex ndc_data_explorer.tex
```

The style file is not vendored here. The draft uses `\usepackage[final]{neurips_2026}`.

Main body is targeted at 8–9 pages excluding references and acknowledgements.
